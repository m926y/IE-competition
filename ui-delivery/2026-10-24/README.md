# 行安双端 UI · 2026-10-24

本目录提供新版管理端与司机端 UI 下载包，供团队接入现有千问办公项目。

## 下载

直接下载 [行安 UI 同步包](./xing-an-ui-2026-10-24.zip?raw=true)，解压后先阅读 `同步说明.md`。

## 包含内容

- 浅紫渐变界面、管理端六个主入口与顶部功能标签、司机端、登录界面。
- `src/` 前端源码、`dist/` 构建产物和 `index.html`。
- `build-reference/` 构建所用依赖与配置参考。
- `driver-chart-fields.patch`：司机评分及历史接口的六维字段补丁，只涉及原后端两处字段白名单。
- `文件校验.json`：包内文件 SHA-256；`同步说明.md`：安装接入、验证与回退说明。

## 接入方式

在原 IE-Agent / 千问网页项目中同步 `src/`、`dist/`、`index.html`，保留原后端与平台环境配置。按说明检查并合并字段补丁，再通过原项目发布入口更新现有网页。构建配置如有不同，请对照 `build-reference/` 合并。

需要重新构建时，在完成合并的原项目中执行：

```sh
npm ci
npm run typecheck
npm run build
```
