# 数据清洗与建模路线

## 1. 为什么不整体解压

原始压缩数据约 25GB。IMU 明文体积可能远大于压缩包，整体解压既浪费空间，也会增加重复扫描成本。`src/data/clean_data.py` 直接读取 gzip，并输出 ZSTD 压缩的 Parquet 或车辆-日期聚合表。

## 2. 安装与运行

```powershell
python -m pip install --target .deps -r requirements.txt
python src/data/clean_data.py --overwrite
```

默认输出到 `data/processed/cleaned/`：

- `vehicle_profile.csv`、`vehicle_profile.parquet`：车辆画像；
- `risk_events.parquet`：清洗后的逐条风险事件；
- `trajectory_daily.parquet`：车辆-日期轨迹聚合；
- `imu_daily.parquet`：车辆-日期 IMU 统计；
- `vehicle_day.parquet`：合并后的车辆-日期基础表；
- `quality_report.json`：数据量、车辆覆盖、日期范围和异常统计。

默认不生成逐点轨迹和逐点 IMU Parquet，以避免磁盘空间不足。确需逐行数据时执行：

```powershell
python src/data/clean_data.py --stages trajectory imu --row-level --overwrite
```

运行前应确保至少保留 35GB～45GB 额外空间。逐行物化不是训练基础模型的必要条件。

冒烟测试：

```powershell
python src/data/clean_data.py --output-dir outputs/cleaned_smoke --sample-files 1 --limit 200000 --overwrite
```

中断后再次运行且不加 `--overwrite`，已存在的阶段会被跳过。

## 3. 主要清洗规则

- 观察期固定为 `[2026-06-01 00:00:00, 2026-08-01 00:00:00)`，即完整 61 天。
- `gpsno` 按字符串保存，避免标识符被当作连续数值。
- 风险事件速度仅保留 0～160km/h 作为清洗值，同时保留原值和异常标记。
- 坐标仅将中国大致边界内的值写入清洗坐标；原始数值和有效性标记仍保留。
- 轨迹距离由厘米换算为公里；负距离和负运行时长不进入汇总。
- 事件类型以 `event_type` 编码为准，名称仅用于展示。
- IMU 不直接假定 X/Y/Z 对应车辆前向、横向和垂直方向；清洗阶段仅生成原轴统计和向量模长。
- IMU 缺失不等同于低风险，后续模型中必须增加数据覆盖率或置信度字段。

## 4. 后续路线

### 阶段 A：完成质量门槛

1. 检查 `quality_report.json` 中三类数据的车辆数和日期范围。
2. 核对画像 500 辆车是否全部出现在风险事件和轨迹中。
3. 计算每辆车 IMU 覆盖天数，不把无 IMU 车辆直接判为安全。
4. 检查单车单日里程、运行小时和事件数的极端值。

### 阶段 B：建立车辆-日期特征

以 `vehicle_day.parquet` 为骨架，增加：

- 每类风险事件的日次数、每千公里次数和每百小时次数；
- 最近 7/14/30/61 天窗口统计；
- 近期相对前期的趋势、活跃天数、最长连续风险天数；
- 事故和未遂事故的次数及距最近一次发生的天数；
- 夜间、高速、疲劳、分心、车道稳定、管理配合等维度；
- IMU 覆盖率、速度源差异、模长波动和极端角速度次数。

### 阶段 C：构造时间标签

- 主验证：6月1日至6月20日生成特征，6月21日至7月31日的事故或未遂事故作为标签。
- 辅助验证：构建多个“过去14～21天特征，预测未来14天”的滚动窗口。
- 同一车辆相邻时间段不得随机分到训练集和验证集。
- 任何标签期内的事件都不得进入对应特征。

### 阶段 D：任务一模型

1. 先训练带正则化的逻辑回归作为基线。
2. 再训练浅层梯度提升树；限制深度和叶子数，防止500辆车小样本过拟合。
3. 用时间验证AUC选择特征和参数。
4. 逻辑回归与树模型进行排名或概率融合。
5. 用验证集选择二分类阈值，预测概率仍保留0～1连续值。

### 阶段 E：任务二评分

建议100分制：历史事故与未遂35%、疲劳分心20%、车辆稳定性20%、道路超速10%、管理配合10%、IMU佐证5%。所有扣分先除以里程或时长，并对低暴露车辆做经验贝叶斯收缩。输出总分、排名、等级、置信度及前三项扣分原因。

### 阶段 F：最终验证

- 预测文件恰好500行，`gpsno`唯一且与画像一致；
- `risk_prob`无空值且位于0～1；
- 代码从原始文件开始可以一次性复现清洗、特征、训练和提交结果；
- 固定随机种子，并保存特征清单、参数和时间切分定义。
