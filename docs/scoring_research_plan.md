# 评分风险证据与单调加性模型实验（2026-09-26）

实施范围：直接风险差区间与趋势检验；四级管理容量与合并B/C的三级风险解释；弱收缩分层Beta-binomial描述性区间；单调加性评分；保持按车辆关联的配对比较和跨期诊断。

在执行开发评价前固定两个候选：固定参考百分位的三段单调加性模型、训练参考风险率r/(r+s)的三段单调加性模型。s仅从训练参考率拟合。每维三个非负斜率系数，总和为维度权重，六维权重和为1、历史最高、疲劳/稳定性不低于道路、IMU至多10%，单维权重相对现有冻结权重变化至多0.05；权重L2系数4、形状偏离线性L2系数4。正式和辅助标签成对逻辑排序损失等权。

训练评分截止6月14日，标签6月15日至28日。开发评分截止6月28日及30日，各后14天正式标签。候选替换门槛：平均AUC至少提升0.01，最差AUC较基线最差退化不超过0.005，平均Top50召回不退化。以开发平均AUC最高的合格候选冻结；没有合格者继续用原模型。

首次开发结果发现两候选均未通过Top50门槛。在尚未评价任何候选晚期表现时，补充冻结一个研究对照：固定取两个候选中开发平均AUC最高者（additive_rate），只作晚期与跨期诊断，不改变替换门槛。正式选择仍为原模型。此补充是开发后确定的诊断安排，不描述为完全预注册实验；不得根据后续回顾结果追加候选或切换正式模型。

配对分层bootstrap用于同一晚期窗口比较AUC/AP及Top-K，按相同车辆抽样。跨期诊断使用7月14日至17日截止的四个14天目标窗口（配置最晚已知日期7月14日）；窗口重叠，按gpsno整组bootstrap估计平均AUC差，不按2000行独立抽样。额外7天诊断用7月15日至21日、22日至28日两个不重叠标签期，但同一司机重复出现，仍不能称为独立个体或新独立测试。

三级风险解释预定义为low=A、middle=B+C、high=D；保留四级管理动作。贝叶斯描述模型：全局率m~Beta(0.5,0.5)，各级p_g|m~Beta(10m,10(1-m))，用当前回顾计数更新并积分m，报告95%可信区间。此处只用于描述，不进入评分训练、选型或未来预测；可信区间不能混称频率学置信区间。

本实验数据均为此前可见的61天历史，无法凭算法增加新的独立标签。真实40天验收仍需组委会提供新真值。区间不重叠不是选型门槛，不能降低置信水平或反复切分阈值制造分离。
